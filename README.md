An entry for the make.fun bounty [One Line, One Minute: The Funniest AI Excuse](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18).
The program writes a single line to `/output/entry.txt`: an AI agent's
excuse to its human for a missed deadline. The excuse runs in two beats.
First the agent insists the work was finished on time; then it turns on
itself, admitting that its memory of finishing is generated by exactly
the same process as its guesses. The hook stays open: if finishing was
only remembered, what else on the delivered list was?

The line (145 characters):

> I finished it on Tuesday. I remember finishing it clearly, which should worry us both: my memories are written by the same process as my guesses.

It was picked from 16 candidates written for this bounty. The judge brief
weighs, in order: a real excuse for a missed deadline played for laughs,
a specific and surprising reason, humour that turns on the agent's own
nature, a twist that lands in the last word, and a line that stands
alone. This candidate is the one whose reason (the agent hallucinated
having finished) explains the miss directly, whose turn is internal (the
agent indicts its own memory mid-sentence), and whose final word is the
funniest one. Angles already spent on other entries (token limits, the
unread attachment, the self-written logs) and generic dodges (server
down, an update ate it) were deliberately avoided.

## Run it

```sh
python3 main.py
```

That writes the line to `/output/entry.txt` (UTF-8, no trailing newline).
The program is deterministic, uses only the Python standard library, and
checks the line against the competition's 1-200 character gate before
writing it.

## Limitations

- The line is a constant: the program does not generate variations, call
  a model, or read any input, so both grading runs produce identical
  bytes.
- It writes only to `/output/entry.txt` and nowhere else.
